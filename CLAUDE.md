# Back Office Portal

Bank-internal admin console governing the Web + Mobile **Corporate Banking**
channels. It configures the systems that move money; it does not move money
itself. Security, auditability, and dual control come before latency.

## Stack (short version)

Next.js 16 (App Router) · React 19 · TypeScript (strict) · MUI v7 + Emotion ·
Tailwind v4 · (planned) Redux Toolkit + RTK Query. Source under `src/`,
`@/*` → `./src/*`.
